# 快速开始

五分钟，从装上到用对。

---

## 1. 先装上

**Claude Code**

```bash
git clone https://github.com/creatememori/devils-counsel.git ~/.claude/skills/devils-counsel
```

目录结构必须是：

```text
~/.claude/skills/devils-counsel/SKILL.md
```

**Claude.ai**：把整个 `devils-counsel/` 文件夹压成 zip，Settings → Capabilities → Skills → 上传。

**其他工具**：打开 `SKILL.md`，全选，贴进系统提示词 / 自定义指令 / 项目规则。它没有依赖，一个文件就是全部。

---

## 2. 第一次说话

不用学语法，把方案扔过去就行：

> 我打算做一个面向独立开发者的订阅制 API 监控服务，月费 19 美元。帮我看看这个方案行不行。

你会收到这样一版回复：

```text
【结论】⚠️ 有条件可做。置信度：中。
【三个要害】
1. …
2. …
3. …
【我需要的一条信息】
…
【下一步】
要我把 22 个模块走完，还是先深挖第 1 个？
```

**注意它没有直接给你完整报告**——这是设计。先用最致命的判断换取你的信任和补充信息，再决定往哪挖。想直接要完整版，说"给我完整报告"。

---

## 3. 八句可以直接复制的咒语

| 你想干什么 | 这么说 |
|---|---|
| 快速判断值不值得做 | 「一句话：这事该不该做？」 |
| 要完整评估 | 「完整报告，22 个模块走完」 |
| 只想知道会怎么死 | 「做个 pre-mortem」 |
| 被夸得太多，想听真话 | 「毁灭模式，别客气，别缓冲」 |
| 心里已经有答案，只想被推一把 | 「温柔点，用提问的方式」 |
| 路演/谈判前练手 | 「陪练模式，你当投资人，我来路演」 |
| 两个方案选一个 | 「法庭模式：控方、辩方、你来判」 |
| 只关心钱 | 「只算机会成本和单位经济」 |

## 4. 强度模式

同一句话，四种模式的开场完全不同。假设你说：

> 我想辞职做一个时间管理 App。

**⚖️ 默认**

> 结论：⚠️ 不建议现在辞。置信度：中高。
> 三个要害：① 时间管理是红海，且用户不为"管理时间"付费，为"不焦虑"付费；② 你没有验证过任何一个人愿意为你的版本付钱；③ 辞职是单向门，你的现金跑道只有 7 个月，低于这类产品 12-18 个月的验证周期。

**🔥 毁灭**

> 别做。这不是一个"要不要辞职"的问题，是一个"你还没开始就想全职"的问题。
> 时间管理 App 的死亡率是 99%，剩下 1% 里活得好的都是自带流量的人。你没有流量、没有差异化、没有验证，只有一腔热情和 7 个月现金。热情不是商业模式。
> 如果你非要听一个理由：你连"哪个具体场景下用户会打开它"都说不出来。这不是产品，是逃避上班的借口。

**🌱 温柔**

> 在决定辞职之前，我想先问你三个问题，你不用急着回答：
> 1. 你上次觉得"时间完全失控"是什么时候？当时你在做什么？
> 2. 那个时刻，你打开手机想找一个什么样的工具？现在市面上有吗？
> 3. 如果这个 App 做出来了，你希望别人怎么向朋友描述它？
> 你的答案里，可能藏着"你想做的"和"用户需要的"之间的差距。

**⚡ 极简**

> 别辞。先做 10 个用户，有人付钱再说。止损：3 个月 0 付费就放弃。

模式可以随时切换，也可以混搭："毁灭模式，但最后给我一段温柔的总结"。

## 5. 怎么读它的输出

| 它写的东西 | 你要注意什么 |
|---|---|
| **结论**（✅ / ⚠️ / ❌） | 这是判断，不是建议。⚠️ 后面一定跟条件 |
| **置信度**（高 / 中 / 低） | 低置信度时，它在替你猜；中，是逻辑推演；高，是有证据 |
| **三个要害** | 按致命度排序，第一个最重要。不要平均用力 |
| **承重假设** | 一旦错了方案就塌的那 1-3 条。其余都是次要的 |
| **kill criterion** | 什么结果算失败。事先写死，别事后找补 |
| **什么证据会让我改口** | 它给自己设的推翻条件。拿这个去验证它 |
| **现在最该做的一件事** | 只有一件。如果你看到三件，说明它没收敛好，让它重来 |

## 6. 怎么回应它

| 你的情况 | 怎么说 |
|---|---|
| 你有新证据 | 「关于 X，我补充一个数据：…」——它会明确说"因为 X，我更新判断" |
| 你不同意但没证据 | 直接说「我不同意」，它会重申或指出你在回避哪一点。**这是设计**：立场不为情绪改变 |
| 你觉得它没懂你 | 「你把我的方案理解成了 A，实际是 B」——它会先重述再判断 |
| 你觉得太狠 | 「轻一点」/「我有点难受」——它会降级，但**不会改结论** |
| 你想停了 | 「停」——立即停止，不追问 |
| 你想收敛 | 「给我收敛报告」——输出 9 段结论 + 一件事 + 决策日志 |

---

## 7. 什么时候该用它，什么时候别用

**用**：不可逆的、代价高的、信息不完整的决策。换工作、读研、创业、架构选型、要不要 All in 某个方向。

**别用**：你只是想倾诉；你需要医疗/法律/税务的具体操作；你正在经历心理危机；你想学怎么操纵别人。

遇到后三种，它会明确说明并转介，而不是硬答。

---

## 8. 一个提醒

这个 Skill 的价值不在于"它说得对"，而在于**它让你在投入之前，被迫看见自己一直在回避的那部分**。

所以最有用的用法不是"帮我判断"，而是：

> 我知道自己想做这件事。请假设它是错的，告诉我为什么。

然后你去看那些理由里，哪一条你驳不倒。
